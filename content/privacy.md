# Privacy

This page covers **allendior.com** and Allen Dior’s private personal software tools that connect to Google accounts (for example a local assistant that reads Gmail/Calendar for work rosters and personal scheduling).

## Who this is for

These tools are built and operated by **Allen Dior** (legal name Allen Ghanghas) for personal use. They are not a public multi-tenant product.

## Email updates on this website

If you use the **Get updates by email** form on allendior.com, your email address is sent over HTTPS to a private form endpoint operated for Allen Dior (`dhanana.in/api/subscribe`, source `allendior`) so Allen can be notified of the signup. This is a **notify-only** capture until a dedicated mailing list provider is connected.

- Used only to send occasional writing/project updates you asked for, or to migrate you onto a proper list later
- Not sold, not used for ads
- You can ask removal anytime: **allendior.ca@gmail.com**
- RSS remains available without giving an email: `/index.xml`

## What data is accessed

When you authorize Google access for a personal tool on this brand, the tool may access only the Google scopes you approve — commonly:

- Gmail (read/send/modify as granted)
- Google Calendar
- Google Drive, Docs, Sheets, and Contacts when those scopes were granted

Typical uses include reading work schedule emails, creating personal calendar events you asked for, and other explicit personal-operator tasks.

## How data is used

- Data is used to run **your** requested personal workflows on devices you control.
- Data is **not** sold.
- Data is **not** used for advertising.
- Tokens and local caches stay on your machines / approved private storage unless you explicitly export them.

## Sharing

Google account data accessed through these tools is not shared with third parties for marketing. Sharing only happens if you ask for it (for example sending an email) or if required by law.

## Retention

Local caches, logs, and OAuth tokens are kept only as long as needed for the tool to work. You can revoke access anytime in your Google Account security settings.

## Your controls

- Revoke app access: [Google Account → Security → Third-party access](https://myaccount.google.com/permissions)
- Delete local tool data on your devices
- Contact: **allendior.ca@gmail.com**

Questions about this policy: **allendior.ca@gmail.com**
