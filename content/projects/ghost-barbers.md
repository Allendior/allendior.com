## The Project

A freelance website built for Ghost Barbers, a local barber shop. The brief was simple: clean, fast, mobile-first, no unnecessary complexity.

## What It Includes

- Shop info, hours, and location
- Services and pricing
- Mobile-optimized layout that works well on the phones customers actually use to find the shop

## Stack

Plain HTML and CSS — no framework overhead, no build step, instant load. Hosted on GitHub Pages.
